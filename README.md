- Sistema de Gestão para Cafeteria 
Sistema em Python para gerenciamento de clientes, produtos, estoque e vendas/pedidos via terminal, com persistência de dados em arquivos CSV.

- O que foi usado:
Pandas — Leitura, manipulação e salvamento dos dados em tabelas
Pathlib — Organização e localização dos caminhos dos arquivos CSV

- O que o programa faz:
Clientes: Permite cadastrar, buscar por CPF, atualizar dados e gerenciar o acúmulo e resgate de pontos de fidelidade.
Produtos: Controla o cardápio, permitindo filtrar por categoria, atualizar estoque e ativar ou inativar itens.
Pedidos: Processa as compras, calcula os descontos dos pontos acumulados e atualiza o status do pedido (como *Pendente* ou *Concluído*).
